## How to Edit this website
- To view and edit this website on your native environment, clone this repository in your local environment.
- Open the folder in an IDE of your choice.
- Install node if not installed already.
- Open the terminal and run this - 
<br> ```npm install```
- You are now working with the copy of the website on your local device.
- To view the website on a local host, run this - 
<br>```npx webpack serve```
- Now open [localhost](http://localhost:8080/) on ```http://localhost:8080/```
